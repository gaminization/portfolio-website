The Editor is a custom block-based content management system designed specifically for the blog. Instead of a traditional text editor, it provides a modular workspace where every element of a post exists as an independent block that can be freely arranged, resized, and customized.
Users can add rich text, code snippets, images, videos, diagrams, terminal outputs, tables, sticky notes, ASCII art, 3D models, and custom widgets, allowing each article to have a unique layout rather than a fixed vertical structure. A drag-and-drop interface makes it easy to organize content visually.
The editor includes a left sidebar for inserting content blocks and templates, a central editing canvas, and a right sidebar containing the table of contents, attachments, quick notes, tag suggestions, and publishing options. It supports autosave, version history, markdown shortcuts, syntax highlighting, drag-and-drop media uploads, and live previews before publishing.
Built with accessibility in mind, the editor supports keyboard navigation, screen readers, responsive layouts, reduced-motion preferences, and touch-friendly interactions. Every published article seamlessly integrates into the blog's floating archive, becoming another discoverable window within the infinite archive interface.
